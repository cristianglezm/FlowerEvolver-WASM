    Class FEService

    simple wrapper around fe wasm module.

    Example

    let fes = new FEService();
    await fes.init(); // must resolve before any other call
    // make a flower with default params
    let flowers = new Array();
    flowers.push(await fes.makeFlower());
    // radius, numLayers, P, bias
    fes.setParams(new FEParams(128, 2, 5.0, -1.0));
    // make a flower with new params.
    flowers.push(await fes.makeFlower());
    flowers.push(await fes.reproduce(flowers[0].genome, flowers[1].genome));
    // mutate child using default mutation rates.
    flowers.push(await fes.mutate(flowers[2].genome))

    extractFeatures

    • extractFeatures(
          generationsJson: string,
          environment?: SOMEnvironment,
      ): Promise<(number[] | null)[]>

      extracts the feature vector of every flower of a batch, once. Rendering is the expensive part of classifying, evaluating or fine-tuning and wasm calls keep no state, so a caller running several steps over the same flowers (e.g. one fine-tuning epoch per call, to show progress) extracts once and passes the vectors (about 1.4 KB as JSON against ~17 KB for a genome) to classifyFeatures()/ evaluateFeatures()/fineTuneFeatures(). Hold them for the length of such a run, not with the stored flowers.

      Parameters

      • generationsJson: string

        stringified {"Generation": [...]}.

      • environment: SOMEnvironment = {}

        see classify(); the vectors depend on it.

      Returns Promise<(number[] | null)[]>

      one entry per input flower, in order: its vector, or null if the genome is malformed/unusable.

      • totalEpochs: number = 0

        epochs of the whole decay, 0 means epochOffset + epochs.
